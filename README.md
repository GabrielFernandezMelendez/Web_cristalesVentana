# Web_cristalesVentana

Landing de cristales para ventanas (variante formal, paleta A) de **Cristales Tutorales**. Mockup para que el cliente elija la versión final.

## Stack
- HTML + CSS + JavaScript, sin frameworks
- CSS organizado con atomic design: `css/atoms`, `css/molecules`, `css/organisms`
- Rutas relativas para que funcione en GitHub Pages

## Despliegue
GitHub Pages desde la rama `main`:
https://gabrielfernandezmelendez.github.io/Web_cristalesVentana/

## Destino final
La versión elegida se convertirá en un tema ligero de WordPress, con cada sección como bloque editable.
